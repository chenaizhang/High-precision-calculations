# README

## 项目简介

这是一个用 **C++ + 单向链表** 实现的“**高精度四则运算计算器**”。
程序将输入的十进制数（可带负号、逗号分隔符与小数点）逐位拆成链表节点，模拟人工手算完成：

- 加法 `+`
- 减法 `-`
- 乘法 `*`
- 除法 `/`（输出最多 20 位小数，并带四舍五入逻辑）

输出支持：

- 千分位分隔符 `,`
- 小数点 `.`
- 负数输出

---

## 功能特性

- ✅ 支持大整数与小数的高精度运算（不依赖 `long long` / `double`）
- ✅ 输入可包含千分位逗号，如 `1,234,567.89`
- ✅ 支持负数，如 `-12.34`
- ✅ 小数对齐处理：加减法会补零对齐小数位
- ✅ 乘法结果小数位数 = 两数小数位数之和
- ✅ 除法输出固定计算 20 位小数（不足补 0），并尝试进行末位四舍五入
- ✅ 除数过小（接近 0）会输出 `ERROR`

## 使用说明（交互输入格式）

程序会提示你输入：

1. 数据数目 `n`（表示要计算多少次）
2. 每次计算输入：

   - 操作符：`+` `-` `*` `/`
   - 左操作数（字符串）
   - 右操作数（字符串）

### 示例输入/输出（示意）

输入：

```
请输入数据数目：2
请输入操作符：+
左操作数：1,234.5
右操作数：6.70
请输入操作符：/
左操作数：10
右操作数：3
```

输出（示意）：

```
1,241.20
3.33333333333333333333
```

## 输入格式规则

操作数是字符串读入，允许：

- `-` 负号（只能出现在首位）
- `,` 千分位分隔符（会被忽略）
- `.` 小数点（用于确定小数位数）

例如以下都合法：

- `123`
- `-999999999999999999.01`
- `1,234,567.8900`

## 实现原理概述

### 数据结构

每一位数字用一个节点表示：

```cpp
struct Node {
    int num;      // 存放 0~9 或其负值（用于符号逻辑）
    Node* next;
};
```

链表在运算前会被 `reverse()`，使低位在表头，便于进位/借位（像手算一样从个位开始）。

### 小数处理

- `xiaoshudian()` 用于统计小数点后位数。
- 加减：将两数小数位补齐到相同长度再计算。
- 乘法：结果小数位数为 `x1 + x2`。
- 除法：内部按“长除法”逐位试商，并扩展 20 位小数。

### 符号处理

通过 `ispositive()`、`negation()`、`dayu0()`、`neg_big()` 等函数组合实现正负号的判断与处理。

## 关键函数说明（速查）

- `append(head, digit)`：在链表尾部追加一位
- `reverse(head)`：反转链表（低位到表头）
- `add(num1, num2)`：高精度加法（含符号处理）
- `sub(num1, num2)`：减法（通过 `negation` + `add` 实现）
- `cheng(head1, head2)`：乘法（逐位相乘累加）
- `chu(head1, head2)`：除法（长除法 + 20 位小数）
- `print_1(head, x)`：用于加减输出（按 x 位小数打印）
- `print_2(head, x)`：用于乘除输出（含小数长度控制/近似四舍五入）
- `delete0(head, x)`：去掉反转链表头部多余 0，并调整小数位数
- `clear(head)`：释放链表内存

---

## 注意事项与限制

- `/` 运算中对“除数过小”的判断由 `toosmall()` 完成：它检查前若干位是否全为 0，若过小则输出 `ERROR`（近似当作除以 0 处理）。
- 输出格式中包含千分位逗号逻辑，但输入逗号位置不做严格校验（读入后会直接忽略）。
- 除法只计算并输出最多 20 位小数（不是无限精度）。
