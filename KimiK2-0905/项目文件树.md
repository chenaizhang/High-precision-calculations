## 文件详细说明

### Cargo.toml
```toml
[package]
name = "KimiK2-0905"
version = "0.1.0"
edition = "2024"

[[bin]]
name = "KimiK2-0905"
path = "src/main.rs"

[dependencies]
```

### src/lib.rs (核心库)
- **BigDecimal结构体**：包含sign、digits、scale字段
- **核心方法**：
  - `parse()`：字符串解析
  - `add/sub/mul/div()`：四则运算
  - `normalize()`：标准化处理
  - `to_string_with_grouping()`：格式化输出
- **错误处理**：BigDecimalError枚举
- **测试用例**：覆盖基本功能和边界情况

### src/main.rs (CLI界面)
- **交互式计算器**：支持连续运算
- **输入处理**：支持quit/exit退出
- **错误提示**：友好的错误信息
- **格式化输出**：普通格式和千分位格式

## 核心数据结构

```rust
pub struct BigDecimal {
    sign: bool,        // true为正，false为负
    digits: Vec<u8>,   // 数字位（从低位到高位存储）
    scale: usize,      // 小数位数
}
```

## 公共API

```rust
impl BigDecimal {
    pub fn parse(input: &str) -> Result<Self, BigDecimalError>
    pub fn add(&self, other: &Self) -> Result<Self, BigDecimalError>
    pub fn sub(&self, other: &Self) -> Result<Self, BigDecimalError>
    pub fn mul(&self, other: &Self) -> Result<Self, BigDecimalError>
    pub fn div(&self, other: &Self) -> Result<Self, BigDecimalError>
    pub fn to_string_with_grouping(&self, grouping: bool) -> String
    pub fn normalize(&mut self)
}
```
